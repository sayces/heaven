# Слой моделей (Model)

Model хранит данные и правила. В MVC это «M»: он не знает про HTTP —
не импортирует `express` и не работает с `req`/`res`.

## Состав

| Файл | Роль |
| --- | --- |
| `user/types.ts` | Тип `User`: `id`, `name`, `password` |
| `user/user.mock.ts` | Стартовые данные, имитация БД |
| `user/user.model.ts` | Методы `create`, `getAll`, `getById`, `removeById`, `updateById` |
| `index.ts` | Реэкспорт `UserModel` |

## Правила

- `id` — строка из `Date.now()`.
- `name` уникален: повторное имя вызывает ошибку.
- `getById` возвращает копию пользователя или `null`.
- `getAll` возвращает копию массива.
- `removeById` возвращает `true`, если запись удалена.
- `removeById` и `updateById` для отсутствующего id бросают `Error`
  (см. «Известные ограничения» в `src/docs.md`).

## Границы

- Model не формирует HTTP-статусы и не пишет ответы.
- Controller не обращается к массиву `users` напрямую — только через методы
  модели.
- Сейчас хранилище — массив в памяти. Если появится БД, она подключается здесь,
  а сигнатуры методов и контроллеры остаются прежними.
